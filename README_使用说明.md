# Copper Quant Options Hedging Lab V6.2

把 app.py 和 options_hedge_lab.py 上传到 GitHub 仓库根目录（覆盖旧 app.py），Streamlit 自动部署。无需修改数据库 Secrets。

**重点：先在左侧加载至少16个月真实日度行情**，才能计算过去约一年四个63交易日周期。输出包含季度对照、总损益、季度均值、最差季度以及未来63日区块Bootstrap模拟。

**期权权利金不是历史真实成交价**：使用前60日真实收益计算历史波动率，乘以可调倍数，输入 Black-76 欧式期货期权模型估算3个月建仓权利金。可调行权价和交易费用。沪铜美式期权不考虑提前行权，无法直接作为实际交易利润。

比较无套保、买入看跌期权、领口、看跌价差、卖出期货。每周期假设100%按连续吨位套保，无法处理实际整手、期权到期日差、换月基差、贸易价差、汇率以及进口品质。与银行或期货公司核对报价后才可考虑交易。

目前没有自动提交到模拟盘的订单：这里是独立的风险研究模块，不会向券商实盘或虚拟账户下单。
