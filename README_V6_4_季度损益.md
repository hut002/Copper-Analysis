# Copper Quant V6.4 — 三个月每期损益 / Return

在动态铜套保标签页新增四个三个月周期（63交易日）的策略损益、季度收益率、固定名义本金期初/期末参考权益、累计损益和累计收益率。

**计算口径**
- 每期损益（PnL）= 假设现货毛利 + 现货铜价变化 + 期权/期货理论损益 - 理论权利金/费用；详情见 `dynamic_hedge_engine.py`。
- 每期收益率 = 当期PnL / 该期固定库存名义本金 × 100%。
- 年度收益率 = 四期PnL合计 / 固定库存本金 × 100%。
- 四期均独立使用相同库存本金，**不是复利**；仅在年度表中另提供假设复投的数学比较，不应认定可真实复投。
- 默认SHFE按CNY、LME按USD。不能把LME美元盈亏直接当成人民币。
- 期权权利金为Black-76理论估值，不是历史实际交易成交；未来模拟并非预测。

## 安装
把补丁中的`dynamic_hedge_engine.py`、`dynamic_hedge_ui.py`替换GitHub仓库根目录对应文件。**无需修改app.py或数据库**。

在新增的“动态铜套保引擎”页选择策略，即显示Q1–Q4各期P&L和Return (%)，下载CSV。
