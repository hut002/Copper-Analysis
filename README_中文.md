# Copper Quant & Paper Trading Terminal V5.0（中英双语本地网页）

## 运行方法

1. 使用 **Python 3.11–3.13**（推荐 3.12），Windows 10/11。解压整个 ZIP 到英文短路径（例如 `D:\Copper_V5`）。
2. 双击 `Start_Windows.bat`。首次运行会创建独立 `.venv` 环境并安装依赖，需联网。
3. 浏览器打开 `http://127.0.0.1:8501`。左侧切换 **中文 / English**。
4. 点击左侧「刷新/加载数据」，可使用公共来源在线抓取、本地 CSV 或上传 CSV。每个市场需至少约 500 行日数据，并满足起止日期完整性检查。主界面不会伪造数据。
5. 从「模拟交易」进入，选择 SHFE / LME 3M；点击「新建 / 重置该模拟账户」。历史回放需要提前加载真实行情；前向模式可在行情软件中核实市场价格后手动录入、写明时间与来源。

## 主要功能

- 市场概览：沪铜主力连续 CNY/吨；伦铜 3 个月 USD/吨。
- 技术与量化：MA20/60、RSI、MACD、波动率、历史 VaR/CVaR、最大回撤、20 个交易日 Monte Carlo（正态对数收益率与区块 Bootstrap）。
- 套保：持货卖出套保、采购买入套保，1M/3M/6M 用户输入合约报价、期限匹配、盈亏情景、估算保证金。
- 历史模拟交易：按日期逐日播放；只能看到当前交易日及之前的行情；在该日提交 MARKET/LIMIT 订单，订单在**下一交易日**按开盘价/限价条件成交。支持撤单、手续费、初始保证金检查、平仓、权益变化、下载交易日志。
- 前向纸面交易：用户从交易终端确认新观察报价（包括时间与来源），本系统按观察价近似撮合，仅为教育实验，非实际可成交买卖价。
- 回测：20/60 等双均线策略，信号在收盘产生、下一交易日开盘执行，支持滑点、手续费和做多/双向。仅为±1手简化策略模型。
- 外部模拟盘：支持从 SimNow/文华/快期等软件下载交易 CSV 并只读预览、下载标准模板；**没有未经授权的自动登录、CTP 实盘或仿真委托接口**。

## 数据要求与限制

支持 CSV 列名 `date,open,high,low,close,volume,open_interest` 或常见对应中文列名；回放委托的次日执行必须有 `open`，否则阻止推进。

- SHFE：公开网站沪铜主力连续行情，仅用于量化研究，并非可连续交易的单一期货合约；正式回测必须处理主力切换、换月、交割和结算价。
- LME：公开第三方 CAD 铜参考序列需核对 3M 价格定义、时区、价格口径及数据许可；3M 滚动报价并不等于固定某一天的交割合约。正式使用可将授权 LME 数据导入 CSV。
- 量化模拟的随机路径**不是未来真实行情**；不会拿 Monte Carlo 路径充作真实撮合价格。
- 交易引擎为本地 SQLite 虚拟账户；默认仅有每手乘数和简化保证金模型，未建交易所逐日盯市清算、涨跌停、停牌、强平、夜盘、价差滑点与汇兑机制。
- SHFE 每手 5 吨、LME 标准铜每手 25 吨；手续费和保证金率为可编辑实验参数，不代表经纪商实时标准。
- SHFE/LME 两个虚拟账户各有币种，不合并权益；数据库文件 `paper_accounts.sqlite3` 存储在当前程序文件夹，重置指定市场/模式会清空该模式交易记录。
- 本地网站只在 `127.0.0.1` 监听，不向外网暴露。不要输入券商账号、交易密码或 API 密钥。

## 文件说明

- `app.py` — Streamlit 中英双语网页
- `quant_engine.py` — 历史行情与量化指标
- `hedge_engine.py` — 套保情景与期限
- `paper_engine.py` — SQLite 虚拟账户/委托撮合
- `backtest.py` — 无前视偏差均线交叉回测
- `Start_Windows.bat` — Windows 一键启动
- `requirements.txt` — 依赖
