# Copper Quant Cloud V6.3 — Dynamic Copper Hedging Engine

## 本次升级
- 保留原有的全部功能与模拟盘；新增独立标签页「动态铜套保引擎」。
- 以左侧加载的沪铜/伦铜**真实历史收盘价**，按过去四个独立的63交易日周期比较：不套保、买入Put、Collar、Put Spread、卖出期货、动态组合。
- 牛/熊/震荡/不确定状态仅使用**各季度期初已经知道的过去行情**判定（20/60/120日均线和过去60日变化），不做未来信息泄漏。
- 默认动态方案：熊市60%空期货+40%买入Put；其他状态100%买入Put。默认不允许卖出Call；仅勾选研究模式才允许区间市50% Collar + 50% Put。权重为理论风险敞口比例，并非建议交易手数。
- 63日五日区块Bootstrap情景，比较5%利润分位数和5% CVaR；下载CSV。
- 内置用户参数：库存名义金额、每周期假设基础毛利、Put/Call行权价比例、理论IV、权利金模型、费用。

## 数据与方法重要限制
1. 无原始历史铜价CSV在此包内；上线后由你现有行情加载功能提供真实铜价，**不能把本次测试用合成数据当做历史回测结果**。
2. Black-76权利金是理论估计，缺少真实历史期权成交价格/隐含波动率曲面；不模拟上期所美式期权的提前行权。
3. 不考虑再生铜品位、货权及基差、美元人民币汇率、海关税费、融资成本和逐日追加保证金；期货连续合约与现货定价也可能存在偏差。
4. 仅四个季度样本不足以稳健判断最优策略；未来情景也不是未来市场实际预测。
5. 动态模型不会写入云端模拟订单、不会自动交易。企业交易前需要独立的治理与审批。

## 推荐部署方法：最小补丁
将补丁包中的三个Python文件放到GitHub仓库根目录：
- `app.py`（覆盖旧文件）
- `dynamic_hedge_engine.py`（新增）
- `dynamic_hedge_ui.py`（新增）

不要上传 `.streamlit/secrets.toml` 或数据库密码。原有 `requirements.txt` 不需更改。

然后提交到 `main`，由 Streamlit Cloud 自动部署。登录后侧边栏加载历史行情（建议3年），进入「动态铜套保引擎」标签页。完整包同样可直接解压到仓库根目录，**但建议只应用以上三文件**。

## 本地测试
`python test_dynamic_hedge.py`
